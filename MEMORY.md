## 🧠 Key Learnings

### Distribution > Building
- Building is the comfort zone. Distribution is where revenue comes from.
- Every product needs an outreach plan before launch.

### ADHD-Optimized Workflow
- One task at a time, completion before moving on
- Step-by-step with checkboxes
- "Ready to continue?" checkpoints
- Status indicators: ✅ ⚠️ 🔴

### Content & Distribution
- **Daily WIP.co posts are essential** — capture everything we do, write pithy progress updates
- Show wins AND fails — authenticity > perfection
- Script: `llm-txt-mastery/scripts/post-wip.js`

### Technical Lessons
- **Disk space kills CI/CD silently** — monitor `/` usage, alert at 85%
- **develop → main flow**: Always push to develop first, Jamie reviews, then merges to main
- **LinkedIn API escaping**: Must escape `( ) | { } @ [ ] < > # \ * _ ~` in commentary field
