> ## Killed: ModelOptix, August 2026
>
> This was an independent AI-model cost optimiser with a catalogue of over 700 models. The app was built but locked behind a waitlist page, and nobody flipped it. Parked in May 2026, then the strategy call. Its infrastructure was scheduled for deletion on 25 August 2026. The fuller README is on the develop branch.
>
> The code stays public under the MIT licence as the record of what was built. No support, no updates. There was no README on this branch; the code is as it was left.
