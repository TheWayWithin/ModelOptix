## 🔍 Ace Not Responding — Root Cause Found

**Issue:** Ace responds to first message ("Hey Ace") but not follow-ups.

**Root cause:** Group messages require @mention to trigger response.
- Log showed: `"skipping group message" reason: "no-mention"`
- Config `ackReactionScope: "group-mentions"` means Ace only responds when mentioned by name

**Fix options:**
1. Mention Ace in each message
2. Change config to respond to all messages in allowlisted group

Jamie needs to decide which approach.

## ⚡ The Real-Time Rule (Learned from Ace)

New principle adopted — update files **immediately**, not batched at end:

1. New task identified → Add to TASKS.md immediately
2. Task completed → Update TASKS.md immediately
3. File updated → Save immediately
4. End of work → Update memory file

**Why:** Context can be lost mid-session. If you batch for "later," later might never come.
