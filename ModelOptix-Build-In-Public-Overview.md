## The Problem We're Solving

### Core Problem
Developers pick an AI model, ship it, and then 6 months later they're probably overpaying - but can't justify stopping to re-evaluate. Meanwhile, 400+ models are constantly changing with no unbiased source to cut through the noise.

### Why This Matters

**The Symptoms**:
- 400+ models and growing - impossible to track manually
- Constant price changes with no central notification system
- Every existing tool has hidden incentives (volume routing, affiliate deals, vendor relationships)
- Developers making decisions on 3-6 month old information

**The Costly Cycle**:
1. Pick model based on available info
2. Ship and move on to other priorities
3. Months pass, landscape changes
4. No time/incentive to re-evaluate
5. Quietly overpaying or underperforming

**The Real Cost**:
- Quietly bleeding 20-40% overspend every month
- Falling behind competitors who optimize their AI stack
- Background anxiety about "am I doing this right?"
- Missing better models that could improve their product

## How ModelOptix Solves This

### The Solution

ModelOptix is a **trust-first AI model advisor** that:

1. **Continuously monitors** your AI/LLM usage across products and functions
2. **Automatically detects opportunities** when better/cheaper models appear
3. **Generates recommendations** based on your specific use case (not generic benchmarks)
4. **Provides Sanity Check** - test recommendations with your own prompts before switching
5. **Tracks savings** and ROI to prove value delivered
6. **Shows trust scores** across 8 dimensions for models and providers

### Key Features (MVP)

| Feature | What It Does |
|---------|--------------|
| **Portfolio Management** | Track all your AI products, functions, and use cases in one place |
| **Smart Recommendations** | Get personalized model suggestions based on your use case (cost, speed, accuracy, context) |
| **Sanity Check** | Test recommendations with your actual prompts before switching |
| **Trust Dashboard** | See trust scores for models/providers across 8 dimensions |
| **Savings Tracking** | Record and visualize all savings from optimization decisions |
| **Real-time Alerts** | Get notified when prices change, new models launch, or trust scores update |
| **Model Comparison** | Compare 2-4 models side-by-side across pricing, performance, trust |

### How It Works

```
1. Add Your Portfolio
```

## Technical Architecture

### High-Level Stack

```
┌─────────────────────────────────────────────┐
│         Cloudflare (Free Tier)              │
│   - Global CDN for JS/CSS/images            │
│   - DDoS protection                         │
│   - SSL termination                         │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│              Railway                        │
│   ┌─────────────────────────────────────┐  │
│   │   Next.js (standalone mode)         │  │
│   │   - App Router (SSR + Client)       │  │
│   │   - API Routes + Zod validation     │  │
│   └─────────────────────────────────────┘  │
│   ┌─────────────────────────────────────┐  │
│   │   Background Workers                │  │
│   │   - node-cron for scheduled jobs    │  │
│   │   - Job locking + heartbeat         │  │
│   └─────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
        ↓              ↓              ↓
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ Supabase │  │ Upstash  │  │ External │
  │ Postgres │  │  Redis   │  │ Services │
  │ + Auth   │  │ (limits) │  │          │
  └──────────┘  └──────────┘  └──────────┘
                                    ↓
                    ┌──────────────┬──────────────┐
                    ↓              ↓              ↓
              OpenRouter      Stripe        Resend
```

### Technology Choices

| Layer | Technology | Why |
|-------|-----------|-----|
| **Frontend** | Next.js 14 (App Router) | SSR for SEO, fast development, React ecosystem |
| **Styling** | Tailwind CSS + shadcn/ui | Rapid UI development, consistent design system |
| **Backend** | Next.js API Routes | Collocated with frontend, simpler deployment |
| **Database** | Supabase (PostgreSQL) | Managed Postgres, RLS for multi-tenancy, real-time |
| **Auth** | Supabase Auth | OAuth (Google, GitHub), session management, RLS integration |
| **Hosting** | Railway | No platform timeouts (for long-running Sanity Checks), predictable costs |
| **CDN** | Cloudflare | Global edge caching, DDoS protection, free tier |
| **Rate Limiting** | Upstash Redis | Distributed rate limiting, free tier (10K commands/day) |
| **Payments** | Stripe | Industry standard, trial + subscription management |
| **LLM Access** | OpenRouter | Access to 200+ models via single API, pricing aggregation |
| **Email** | Resend | Developer-friendly, transactional emails |
| **Analytics** | PostHog | Product analytics, feature flags, self-hosted option |

### Architecture Principles

**1. Monolithic for MVP**
- Single Next.js application containing all features
- Faster to build and iterate
- Can extract services later if needed

**2. Multi-tenancy via RLS**
- Row-based isolation with `user_id` column
- Supabase Row Level Security policies
- No complex tenant routing

**3. Job Safety**
- Distributed locking via Postgres
- Heartbeat mechanism (30s interval)
- Reaper job for stuck job recovery
- All background jobs use locking pattern

**4. Security-First**
- CSRF protection (Origin/Host validation)
- Rate limiting on all API routes
- Cloudflare IP extraction for accurate limits
- Service role for privileged operations only
- RLS for user data isolation

**5. Cost-Conscious**
- Free tiers where possible (Cloudflare, Upstash, Supabase)
- Railway starter plan (~$5-20/mo)
- OpenRouter for LLM access (pay per use, no minimum)
- **Total infrastructure: ~$5-45/month**

## Database Schema (High-Level)

### 17 Tables Across 4 Domains

**User Domain** (4 tables):
- `user_profiles` - User accounts, subscription tier, is_admin
- `products` - AI products users are tracking
- `functions` - AI functions within products
- `use_cases` - Requirements for each function (cost, speed, accuracy priority)

**Model Domain** (6 tables):
- `providers` - API providers (OpenRouter, OpenAI, Anthropic, etc.)
- `models` - AI models (GPT-4, Claude 3.5 Sonnet, etc.)
- `model_provider_pricing` - Pricing by model/provider combo
- `model_trust_scores` - Trust scores across 8 dimensions
- `parameter_support` - What parameters each model supports
- `editorial_overrides` - Manual corrections to automated data

**Action Domain** (4 tables):
- `opportunities` - Recommendations for model switches
- `sanity_checks` - User tests comparing models
- `alerts` - Notifications about price changes, new models, trust updates
- `notification_preferences` - User alert channel configuration

**Infrastructure Domain** (3 tables):
- `job_runs` - Background job execution tracking (locking, heartbeat)
- `webhook_events` - Stripe webhook idempotency
- `usage_tracking` - Monthly tier limit tracking

**Q: What makes this different from OpenRouter, OpenAI Playground, or ArtificialAnalysis.ai?**

**Q: How do you make money if you're independent?**

A: Subscriptions only. No affiliate deals, no referral fees, no data selling. We make money when users save money and stay subscribed. Our incentives are aligned with yours.

**Q: Why should I trust your trust scores?**

A:
1. **Methodology is transparent** - we show sources, reasoning, confidence

3. **We have no incentive to lie** - structural independence means no conflicts

**Q: What if I'm happy with my current model?**

A: Perfect! ModelOptix will monitor for you and only alert when something meaningfully better appears. Set it and forget it. No action needed unless opportunities arise.

**Q: Is this just for people spending $1000s on AI?**

A: No! Free tier exists for makers spending <$50/month. Even small optimizations compound. Plus, trust and quality matter regardless of spend.

**Q: Can I try before committing?**

A: Yes! 7-day trial with full access to Growth tier features. Plus 30-day money-back guarantee on all plans.

**Q: What if ModelOptix recommends a model that doesn't work for me?**

A: That's why we built Sanity Check - test with your actual prompts before switching. No pressure to act on any recommendation. Dismiss what doesn't fit.
